# Dip Buying Event Study

This project explores a simple question:

> After a large market drop, is buying immediately a good idea?

## Method

- Define large down days using historical percentiles
- Enter at next day's open
- Hold for fixed periods
- Compare across different market conditions

## Key Finding

Time-based dip buying alone does NOT provide a stable edge.

- Returns are inconsistent
- Drawdowns are often larger
- Risk-reward is not attractive

## Conclusion

> Buying just because the market dropped is not enough.

## Next Step

Move from time-based entry → signal-based entry
